# Skills and agents

Instruções reutilizáveis para arquitetura de soluções, engenharia de IA,
integrações, auditoria de métricas, revisão com crítica e réplica e versionamento
Git. O catálogo é mantido por mudanças revisadas e distribui somente conteúdo
genérico, sem a configuração de uma instalação particular.

Esta base define a licença, os acordos de contribuição e o manifesto da
distribuição. As skills e seus recursos de validação entram por pull requests
com escopo e verificações explícitos.

## Limites e licença

Instruções não concedem permissões de execução e não substituem testes. Uma
revisão multiagente também pode errar; sua superioridade geral não é presumida.
Cada operador escolhe as ferramentas e configura seu próprio ambiente.

Conteúdo de autoria do projeto sob [licença MIT](LICENSE). Skills e plugins de
terceiros mantêm suas próprias licenças e não são espelhados automaticamente.
