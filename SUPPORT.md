# Suporte

Use as [Issues deste repositório](https://github.com/imvictorsfriend-maker/skills-and-agents/issues)
para relatar bugs, fazer perguntas ou propor melhorias. O atendimento depende
da disponibilidade dos mantenedores, sem prazo de resposta garantido.

Ao abrir uma issue, informe:

- A skill, o agente ou o script afetado e a versão ou o commit utilizado.
- O sistema operacional e as versões de Python, Git e GitHub CLI pertinentes.
- Um exemplo mínimo com nomes e dados sintéticos, além dos passos para reproduzir.
- O comportamento esperado, o observado e o código de erro, quando houver.
- Quais verificações foram locais ou simuladas e quais acessaram o GitHub.

As issues são públicas. Revise o texto e os anexos antes de enviar. Não inclua
tokens, credenciais, mapas reais de repositórios, caminhos pessoais, nomes de
clientes, dados restritos ou logs privados. Substitua esses elementos por um
exemplo sintético que preserve o problema. Um código de erro e a etapa afetada
costumam ser suficientes para iniciar o diagnóstico.

Se não conseguir reproduzir o problema sem informação restrita, descreva apenas
o comportamento e essa limitação. Não publique a evidência sensível na issue.

Veja a [instalação](docs/installation.md) e o
[fluxo da integração com GitHub](docs/github-integration.md) antes de configurar
conexões ou permissões. A distribuição não fornece credenciais nem configura
automaticamente os hooks do operador.
